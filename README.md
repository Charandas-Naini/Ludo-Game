# Ludo Game (Cocos2d)

A classic **Ludo** game built with **Cocos2d**, featuring offline multiplayer on a single device and AI opponents.

## 🎮 Features
- Classic Ludo board game rules
- Play with friends on the same device (no server required)
- AI opponents for single-player mode
- Smooth pawn movement and animations
- Configurable board colors

## 🛠 Tech Stack
- Engine: Cocos2d (v3.x)
- Language: TypeScript
